# Портфолио Владиславы Задорожной

Портфолио графического дизайнера. Сохранены прежние шрифты, чёрно-белая палитра с розовым акцентом, меню и анимации.

## Запуск

```bash
npm run dev
```

После запуска откройте `http://localhost:5173`.

## Структура

- `index.html` — главная страница;
- `case-social.html` — графика для Клуба Автоспорта ИТМО;
- `case-presentations.html` — презентации и цифровой буклет;
- `case-lighthouse.html` — фирменный стиль «Дома маяков»;
- `case-web.html` — подборка сайтов и макет интернет-магазина;
- `case-vtb.html` — кейс платёжного терминала;
- `case-cosmetics.html` — кейс интернет-магазина косметики;
- `case.html` — кейс лендинга агентства недвижимости;
- `resume.html` — резюме с печатной версией;
- `assets/` — фотографии, документы и шрифт;
- `styles.css` — общая визуальная система;
- `script.js` — меню, анимации и интерактивность.
- `graphic.css`, `graphic.js` — оформление новых проектов, просмотр изображений и листание слайдов.

Материалы кейсов хранятся в `assets/cases/`, а оформление каждой кейс-страницы — в отдельном CSS-файле.

## Подборка материалов

Основные проекты: соцсети, презентации, фирменный стиль и WEB-дизайн. В WEB-подборке размещены превью и ссылки на Бестоффер и Marvel Print; интернет-магазин обозначен макетом, а не действующим сайтом. Дополнительная ссылка на главной ведёт только в кейс ВТБ. Галерея разделена на графику и фотографию; видимые подписи под работами удалены, описания для доступности сохранены. Названия проектов и разделов сформулированы прямо, общие теги удалены. Моушен указан как дополнительный навык; видеокейс не добавлен, поскольку среди материалов нет видео. Хакатон ВкусВилла не добавлен без материалов. Y2K не включён в основные кейсы, чтобы оставить подборку компактной и не смешивать чужие референсы со своими работами.

Изображения для графической версии находятся в `assets/graphic/`. Полные исходные презентации доступны отдельно в `assets/docs/`. Макеты, опубликованные как учебные и командные, не обозначены коммерческими заказами; прогнозы на слайдах не заявлены результатами работы дизайнера.

Презентации оформлены как подборка самостоятельных проектов с навигацией по названиям. Общая палитра страницы — чёрно-белая с розовым акцентом; исходные цвета работ сохранены внутри изображений. Превью состоит из девяти слайдов: каждый из трёх столбцов посвящён одной презентации. При наведении и фокусе с клавиатуры слайды собираются в сетку, на сенсорных устройствах сетка показана сразу. «Bambook», «Подвези» и «Альфа Старт» показываются по одному слайду: кнопки, клавиатура и мобильные свайпы. Буклет коучей сохраняет горизонтальную прокрутку без видимой полоски. Слайды отделены от фона, увеличение отключено, полные PDF доступны отдельно. Изображения заново экспортированы напрямую из исходных PDF через `scripts/convert-presentation-assets.mjs`: версии 1800 и 3200 пикселей по длинной стороне, WebP без потерь, выбор разрешения через `srcset`. Общая плитка больше не используется как источник отдельных слайдов. В соцсетях оставлен только Клуб Автоспорта ИТМО, шесть работ. Стрелки поверх изображений убраны, увеличение по нажатию сохранено в галерее, автоспорте и фирменном стиле.

Последний набор из папки `избранное для галереи` подготовлен скриптом `scripts/convert-gallery-assets.mjs`: 13 графических работ и 8 фотографий. Дополнительные работы вне выбранной папки не подмешиваются. Изображения показаны целиком, с исходными пропорциями, и открываются крупнее без смешивания подборок. Число колонок адаптируется к экрану; смешанный порядок работ остаётся стабильным при обновлении страницы. Заголовки используют общий положительный межбуквенный интервал `--heading-tracking`; архивная продуктовая версия не изменена.
